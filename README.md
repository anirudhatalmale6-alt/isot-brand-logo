# Insurance School of Texas — Brand Logo

Final logo files for insuranceschooloftexas.com. Palette: Navy `#15305a`, Burgundy/Red `#9c1c28`, White.

## Files
| File | Use |
|------|-----|
| `isot-logo.svg` | Primary scalable vector. Text is converted to outlines — no fonts needed. Use anywhere (website, print, signage). |
| `isot-logo-transparent.png` | 1500×1675 transparent PNG. Web, social, documents. |
| `isot-logo-white-bg.png` | Same logo on a white background. |
| `isot-logo-navy-bg.png` | Same logo on a navy background (for dark headers). |
| `favicon.ico` | Browser-tab icon (16/32/48/64px). |
| `favicon-512.png` / `favicon-32.png` | PNG icons (circular seal). |
| `apple-touch-icon.png` | 180×180 icon for iOS home-screen bookmarks. |
| `isot-logo.pdf` | Vector PDF for print/advertising vendors (scales to any size, no fonts needed). |
| `isot-logo-white.jpg` | High-res JPG on white for ad platforms that require JPG. |
| `isot-logo-editable-source.svg` | Editable source (live text using Google Fonts Oswald + Roboto Slab) if the wording ever needs changing. |

All artwork is original and owned by Insurance School of Texas.
